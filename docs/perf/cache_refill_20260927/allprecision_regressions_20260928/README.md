# Revised all-precision FMOVE.S regression results

The corrected paired run passed all six existing regression targets with both original baseline FPU and revised candidate: `fpu`, `fpu_frames`, `fpu_resume`, `mmu`, `exceptions`, and `fpu_normalize` (12 terminal PASS results). The tests use the existing full-core CPU bus model; they do not establish whole-machine, OS, hardware, timing, or performance behavior. Candidate FPU bus phases changed only for the FPU program: phase 0 remained 103,656 cycles; phases 1 and 2 were 148,700 versus baseline 148,702. All other reported phase counts match. These are regression counters, not a guest benchmark.

Source identities: baseline `ap040_fpu.v` SHA-256 `2d53db3ae4a04310add04eeb7919f0219197a98827ed92e410e6d4a4a90f5465`; candidate SHA-256 `55ff9b3cd1d59069ec0b94ca17e4dc3a8c87ac031317902285444d92643724a2`. The only change from prior FPU candidate `73bc156d147e4f8b1c7ee08f0bb03c7f1cd720d4e78293d8252f63bf992f0b1f` removes the `fpcr[7:6] == 2'b00` eligibility restriction. No other RTL/test source changed. Full feature flags, QSF reference, core/prefetch, MMU, cache, and test inputs are pinned in `profile.json`, `source_comparison.json`, and `input_manifest.sha256`. At runtime the runner verified 100 immutable manifest entries before and after the paired suite; it does not hash generated logs or outputs.

The first attempt is preserved under `attempt1_path_truncation/`. Baseline FPU passed, then baseline frames failed to load its intended test program because the 130-byte absolute `+prog` path overflowed the existing TB’s 128-byte filename buffer. The corrected runner executes `vvp` with the output directory as working directory and a checked short hex basename; no TB or RTL edits were made. The first-attempt failure logs and source runner are retained separately from the corrected run.

`check_results.py` is portable Python 3 standard-library code. Run it against either this archive directory or the complete scratch `outputs` directory, e.g. `python3 check_results.py .`. It verifies all 12 terminal logs, fatal/error markers, bus phase summaries, and log hashes. Compiled VVP files, program images, binaries, and other generated build outputs are omitted from this compact archive; complete scratch outputs remain under `scratch/fpu_normal_single_allprecision_regressions_20260928/outputs/`.

The six-target suite has not been run through the Quartus flow or on hardware. The immutable input manifest SHA-256 is recorded in `run_record.json`; the result’s manifest identity matches it.
