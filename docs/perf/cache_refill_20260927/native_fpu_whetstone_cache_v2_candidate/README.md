# Native Whetstone with cache-v2 — one candidate run

The cache-v2 candidate completed the native tEsT12000 selector1 Whetstone fixture in **8,541,493 loop cycles**, versus **8,724,166** in the already-qualified matched 6c baseline: 182,673 fewer cycles (**2.0939%**), equivalent to **2.1387%** higher throughput for this single run. Candidate runtime/ABI and passive-profile checkers passed, SDRAM protocol errors and BERR/interrupt counts were zero, and the final ABI, code, globals, and stack captures match the baseline byte-for-byte.

This is a single native-kernel simulation with a modeled SDRAM path and ROM latency 6. It has no independent numerical oracle and does not establish full-machine, FPGA timing, or hardware performance. Coarse attribution counters changed alongside the runtime: external read-via-bus32 episodes were 9,773→0, C_PASS occupancy 804,428→630,743, and C_FILL occupancy 8,294→8,300. The baseline's separate address/path replay found 9,630 clean first-line misses at physical 0x00600eae; the candidate run did not use that per-event classifier. Do not claim the aggregate counters prove the exact fate of those individual accesses.
